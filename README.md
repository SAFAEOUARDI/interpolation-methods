# interpolation-methods
Comparison of Lagrange, Newton and Hermite interpolation methods

This project compares three polynomial interpolation methods:

- Lagrange interpolation
- Newton interpolation
- Hermite interpolation

Two functions are studied:

- f(x) = exp(x)
- f(x) = sin(x)

The interpolation is tested with 3, 5 and 7 points.

The results are compared using graphs and interpolation errors.
